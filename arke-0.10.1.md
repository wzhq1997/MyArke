(2026-11-27)

### Fixes

- With single-click opening, Alt+click (or Alt+double-click) opens the item's Properties, as in File Explorer (#493)
- Back and Forward now go through Home and the Recycle Bin too, like any folder (#490)
- A cloud folder (such as WPS Cloud) that its sync program fills a few seconds after you open it now shows the files as they arrive, instead of staying empty until you leave and come back (#319)
- While the name-conflict question is open, the notification no longer says the move or copy is done, and the final count reflects your choices
- The favorites tiles now belong to Favorites: hiding Home no longer hides them, and hiding Favorites hides the tiles together with the list. If you hid Home only to get rid of the tiles, hide Favorites instead (#463)
- "Folders: Before files" again puts folders after the files when sorting in descending order, like File Explorer. A new "Always first" keeps them on top in both directions; if you preferred 0.10's behavior, pick it in Settings (#499, #435, #386)
- Menus taller than the screen now fit on it and scroll, so every item can be reached; the Cut, Copy, Rename and Delete buttons stay in view, and Home and End jump to the first and last item
- The mouse back and forward buttons now act when released, like File Explorer and browsers, instead of when pressed (#497)
- The Properties window opens on the same monitor as the window it was opened from (#466)
- Holding Shift while clicking Delete deletes permanently after asking, and Space confirms the "Delete permanently?" dialog, both as in File Explorer (#517, #422)
